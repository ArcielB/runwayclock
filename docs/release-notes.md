RunwayClock is a local-first, explainable no-work runway calculator for Linux.

Install or update without root access:

```bash
curl -fsSLO https://github.com/ArcielB/runwayclock/releases/latest/download/runwayclock-installer.sh
bash runwayclock-installer.sh
```

Debian and RPM packages are also attached for native package-manager
installation. The AppImage powers the universal per-user installer.
`SHA256SUMS` covers every downloadable asset. Financial data remains local and
is never bundled.
